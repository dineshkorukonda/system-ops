02 / Get started

Your server.
Your console.

Native Ubuntu/systemd gives the console its host view. Review the installer, choose your credentials, and open the dashboard through an SSH tunnel or HTTPS.

Prefer Docker? The image includes the console with a narrower view of host services. Check the deployment comparison before choosing.

03 / Project principles

Built to be inspected.
Documented to be useful.

The code, configuration, and operating guides are open. Start with the sources you have, understand the permissions they need, and keep a recovery path outside the dashboard.

Read the architecture →
  • Clear deployment boundariesSingle-host administration, with native and Docker capabilities explained.
  • Measurements with contextResource use depends on configuration. Reproduce workloads and inspect their conditions.
  • Unknown stays unknownMissing and stale observations should not be counted as healthy.
  • Optional tools, explicit costsExternal monitoring and metrics systems have their own resource requirements.
